# Trading Game — شهرِ معامله‌گر

یک بازی موبایلی فارسی با داستان و پیشرفت مرحله‌ای؛ ترکیبی از بازسازی خانه، ساخت شهر و تمرین معامله‌گری با سرمایه کاملاً مجازی. بازی از صفحه صرافی‌مانند قبلی بازطراحی شده است.

## حلقه اصلی بازی
- شروع در خانه‌ی قدیمی آریا و باز کردن بخش‌های تازه از داستان
- انتخاب دارایی شبیه‌سازی‌شده (طلا، یورو/دلار، نفت یا بیت‌کوین)
- باز کردن و بستن معاملات مجازی خرید/فروش و مشاهده نتیجه در کارنامه
- دریافت سکه، ستاره و تجربه از نتیجه معاملات
- خرج کردن پاداش‌ها برای بازسازی خانه و باز کردن بخش‌هایی از شهر
- ذخیره پیشرفت محلی روی همان دستگاه

## مهم
تمام موجودی‌ها، قیمت‌ها و معاملات ساختگی و صرفاً درون بازی هستند. این نسخه به صرافی یا کارگزاری وصل نمی‌شود و هیچ سفارش واقعی ثبت نمی‌کند. نتیجه معامله می‌تواند مثبت یا منفی باشد؛ سود تضمین‌شده نیست.

## اجرای محلی
پروژه با Capacitor 6 بسته‌بندی می‌شود. نیازمندی‌ها: Node.js 20، Java 17 و Android SDK.

```bash
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

APK آزمایشی در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## ساخت خودکار APK
GitHub Actions با هر push به شاخه `main` پروژه اندروید را می‌سازد و فایل APK را به‌عنوان Artifact نگه می‌دارد. در مسیر **Actions → Android APK → Run details → Artifacts** فایل `trading-game-debug-apk` را دریافت کنید. برای انتشار نسخه جدید، فایل APK را از artifact استخراج می‌کنیم تا لینک مستقیم `.apk` ارائه شود.
