# Trading Game — شهرِ معامله‌گر

یک بازی موبایلی فارسی با الهام از چرخه‌ی پیشرفت و بازسازی مرحله‌ای بازی‌هایی مانند Homescapes؛ با این تفاوت که هسته‌ی مراحل، چالش‌های معامله‌گری با سرمایه‌ی کاملاً مجازی است.

## هویت بازی
- شخصیت اصلی: نئو (NEO)
- وگا (VEGA): مربی تحلیل بازار
- ریون (RAVEN): رقیب داستانی
- اطلس (ATLAS): مربی مدیریت سرمایه
- سبک: بازی داستانی موبایل، پیشرفت مرحله‌ای، بازسازی خانه و مأموریت‌های معاملاتی
- محیط متاورسی و حرکت آزاد سه‌بعدی جزو اهداف این نسخه نیست.

## حلقه‌ی اصلی بازی
1. بازیکن یک دارایی شبیه‌سازی‌شده مانند طلا، EUR/USD، نفت یا بیت‌کوین را انتخاب می‌کند.
2. نمودار قیمت را بررسی می‌کند و برای دور بعد، جهت صعود یا نزول را پیش‌بینی می‌کند.
3. نتیجه‌ی چالش به موجودی مجازی، سکه، ستاره و تجربه اضافه می‌شود؛ پیش‌بینی نادرست نیز ممکن است موجودی مجازی را کاهش دهد.
4. ستاره‌ها و سکه‌ها برای بازسازی پنجره‌ها، سقف، باغچه، آشپزخانه و اتاق کار مصرف می‌شوند.
5. با پیشرفت و بازسازی، داستان و فصل‌های جدید باز می‌شوند.

## وضعیت داده‌های بازار
نسخه‌ی فعلی از قیمت‌های پایه و نوسانات شبیه‌سازی‌شده درون برنامه استفاده می‌کند. اتصال به قیمت واقعی بازار هنوز پیاده‌سازی نشده است. در نسخه‌ی آینده، منبع داده‌ی واقعی و رفتار آفلاین باید جداگانه اضافه و آزمایش شوند. هیچ سفارش واقعی ثبت نمی‌شود.

## ذخیره‌سازی
پیشرفت بازی در حال حاضر به‌صورت محلی در مرورگر یا وب‌ویو دستگاه با localStorage ذخیره می‌شود.

## ساخت APK اندروید
پروژه با Capacitor 6 بسته‌بندی می‌شود. نیازمندی‌ها: Node.js 20، Java 17 و Android SDK.

```bash
npm install
npx cap sync android
cd android
./gradlew assembleDebug
```

APK آزمایشی در مسیر android/app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

GitHub Actions با push به شاخه main یا اجرای دستی workflow، APK را می‌سازد و آن را به‌عنوان Artifact منتشر می‌کند. در GitHub به مسیر Actions → Android APK → Run details → Artifacts بروید و فایل trading-game-debug-apk را دریافت کنید.
